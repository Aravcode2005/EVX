# EvolVIT website

Responsive single-page static website based on the supplied 2025–26 club PDF. Open index.html locally. No dependencies or build step required.

Deploy using an authenticated Vercel CLI: `vercel --prod` from this directory. For Vercel import, select Other, leave build command empty, and use the project root as output directory.

All six teams, four events, winners, internship partners, selection stages, and named faculty are included. The source does not supply a member roster or event dates; no names or dates were invented. Event details and winners expand on click. Photos are extracted from the supplied PDF.
